# 会議室予約（apps/cp/scheduler）

チャットに「明日14時から1時間 会議室A 定例会議」のように送ると、日付・時間・会議室・用件を読み取って予約します。

- 読み取りは決まったルールで行います（AI は使いません）。足りない項目はチャットで聞き返します。
- 同じ会議室・時間帯の予約が重なる場合は、別の時間を聞き返します。
- 予約はこのブラウザ内（localStorage）にだけ保存されます。
- DeskNet's とは直接通信しません。「DeskNet's 取り込み用 CSV」をダウンロードし、DeskNet's の CSV 取り込みで読み込みます。
  （DeskNet's と直接連動させる場合は AI担当に相談が必要です）
