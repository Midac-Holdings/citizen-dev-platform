# タスクリ（張りぼて版）

受信メールからAIが見つけた「今日やるべきタスク」を一覧にするアプリです。
いまは**サンプルデータ**で動く画面だけで、メールやSharePointとはつながっていません。

- タブ：今日やる（期限が今日以前＋期限なしの優先度高・中）／未着手／完了済み
- 各タスク：優先度・種類・期限、元メールの差出人と件名、AIの判断理由（開いて読める）
- 完了・対象外にする・未着手に戻す、実行時刻の設定（このブラウザ内にだけ保存）

## 本番化で差し替えるところ
`src/tasks.ts` の `loadTasks` / `saveStatus` / `loadSettings` / `saveSettings` だけを、
AI担当が用意する部品（自分のタスクの取得・状態の更新・設定の保存）に置き換えます。
タスクの項目は、基盤の SharePoint リスト `TaskuriTasks` と同じにしてあります。
